The system comes with me.

I don’t start from zero. Every project leaves behind a better way to work — clearer decisions, reusable components and stronger checks. The next one starts from there.

01 / How I think

Explore → Decompose → Understand
Build → Evaluate → Iterate

I build understanding
horizontally.

My depth is in connecting disciplines, understanding systems and solving problems across boundaries.

I start with the problem, the person using the system and the outcome that matters. Then I break it into parts I can investigate, build and evaluate.

03 / AI

AI changed
the equation.

AI didn’t replace my need to understand technology. It changed how far that understanding can take me.

I use AI for research, implementation, critique and testing.

I inspect the output, understand the important parts and decide what is ready to ship.

04 / How I build

Problem first.
Tool second.

I don’t need to know the answer. I need to know how to systematically get to the answer.

I make assumptions explicit, keep decisions traceable and evaluate the whole flow. Every project leaves behind something I can use in the next one.

  1. 01

    Problem

    Who is this for, and what needs to change?

  2. 02

    Research

    Understand the constraints and test the assumptions.

  3. 03

    Architecture

    Choose the simplest structure that solves the problem.

  4. 04

    Modules

    Break the system into parts with clear responsibilities.

  5. 05

    Implementation

    Get the complete flow working early.

  6. 06

    Evaluation

    Check the output, edge cases and failure paths.

  7. 07

    System log

    Record the decisions and what changed.

  8. 08

    Iteration

    Use what I learn to improve the next version.

05 / Taste

The first solution
is rarely the solution.

I look at the complete experience: the flow, the language, the visual hierarchy and what happens when something goes wrong.

Then I change what isn’t working. Running code is a starting point. The result still has to make sense to the person using it.
